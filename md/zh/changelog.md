# 公开更新记录

这里整理人生笔记Real 在 App Store 已公开发行的近期 iPhone／iPad 版本。最近核对日期为 **2026 年 9 月 26 日**，当时公开最新版本为 **1.22.16**。

以下是公开发行说明的摘要；日期统一按 UTC 记录。各设备显示的本地日期可能相差一天，Android 渠道的版本请以实际下载页面为准。

| 版本 | 发行日期（UTC） | 更新内容摘要 |
|---|---|---|
| 1.22.16 | 2026-09-20 | 改善编辑页媒体面板与软键盘的切换动画；避免媒体面板与文末图片预览同时出现；修复小屏设备内容溢出。 |
| 1.22.15 | 2026-09-19 | 公开说明列出同 Wi-Fi 局域网换机传输、移动网络同步开关与同步状态优化、媒体添加体验改进；回忆视图和排序集中到更多菜单，支持随机卡片和双列展示；调整置顶签名与会员页面。 |
| 1.22.14 | 2026-09-17 | 公开说明同样包含局域网换机传输、同步状态、媒体选择、回忆展示、四个主页面的置顶签名和会员页面改进。 |
| 1.22.13 | 2026-09-01 | 新增个性化主题入口；长按底部加号可快速录音、拍照或选择媒体；部分设置移到对应功能页面；优化心情日历。 |
| 1.22.12 | 2026-08-25 | 修复照片分类中 Live Photo 作为静态照片选择的问题；改进跨分类、日期分组及分页时的选择状态，避免重复添加。 |
| 1.22.11 | 2026-08-24 | 开放多设备同步；正文混排和评论支持视频、音频；相册选择器支持快速切换媒体类型；修复随机回顾内容对应错误及卡片闪烁等问题。 |
| 1.22.10 | 2026-08-07 | PDF 导出可包含天气和心情；改进正文图片尺寸、相册选择及启动加载；优化日记串浏览，修复旧 ZIP 备份导入后数据无法显示等问题。 |

# Public Release Notes

This page summarizes recent iPhone and iPad versions of Lifelog Note publicly released on the App Store. The latest check was **September 26, 2026**, when the current public version was **1.22.16**.

These summaries follow the public release history. Dates use UTC, so the local date displayed on a device may differ by one day. Check the relevant download channel for Android versions.

| Version | Release date (UTC) | Summary |
|---|---|---|
| 1.22.16 | 2026-09-20 | Improved transitions between the editor’s media panel and keyboard; prevented the media panel and end-of-entry image preview from appearing together; fixed content overflow on smaller screens. |
| 1.22.15 | 2026-09-19 | The public notes list same-Wi-Fi device migration, a cellular sync option and clearer sync status, and improvements to adding media. Memory views and sorting moved into the More menu, with random cards and a double-column view; pinned signatures and the membership page were updated. |
| 1.22.14 | 2026-09-17 | The public notes also cover local-network migration, sync status, media selection, memory views, pinned signatures across the four main tabs, and membership page improvements. |
| 1.22.13 | 2026-09-01 | Added access to theme customization and quick recording, camera and media actions by holding the bottom “+”. Moved some settings to their related pages and improved the mood calendar. |
| 1.22.12 | 2026-08-25 | Fixed selecting Live Photos as still images from the Photos category. Improved selection state across categories, date groups and pages, including duplicate-selection handling. |
| 1.22.11 | 2026-08-24 | Opened multi-device sync; added video and audio support within entry text and comments; enabled quicker media-type switching in the picker; fixed mismatched random-memory content and card flickering. |
| 1.22.10 | 2026-08-07 | Added weather and mood to PDF exports; improved inline image sizing, media selection and startup loading; refined thread browsing and fixed issues including missing data after importing older ZIP backups. |
